Per-Bot DeepSeek — stay on cursor

Default is Grok 4.6. Assigned UUIDs hop to api.deepseek.com using
~/sand-data/deepseek.env (DEEPSEEK_API_KEY=...). Unassigned Bots get a
raw Cursor session (no Proxy). Live id is lazy conv= at create
(where=store) or where=none.

Do NOT:
  ./adapters use deepseek
  ./adapters recover
  ./adapters restart-host
  python3 brain-install-bundle.py

Intro dead / out of sync: fully Quit Grok Bot and reopen. Stay on cursor.
Reset computer last.

Attach (Grok already chats; provider is cursor):

  1. Copy from Explorer (DURABLE copies must live under sand-data —
     sand-host is wiped on Computer recover / host update):
       tools/brain-router.cjs         -> ~/sand-data/brain-router.cjs
       tools/brain-router.cjs         -> ~/sand-host/brain-router.cjs
       tools/patch-brain-hook.py      -> ~/sand-data/patch-brain-hook.py
       tools/ensure-brain-overlay.py  -> ~/sand-data/ensure-brain-overlay.py
       tools/brain-assign.py          -> ~/sand-data/brain-assign.py

  2. printf 'DEEPSEEK_API_KEY=sk-...\n' > ~/sand-data/deepseek.env
     chmod 600 ~/sand-data/deepseek.env

  3. python3 ~/sand-data/ensure-brain-overlay.py
     (or: python3 ~/sand-data/patch-brain-hook.py)
     Fully Quit Grok Bot, reopen, Create new Bot.
     Do not restart-host.

  4. grep -F '[sand-brain]' /tmp/sand-host-manual.log | tail -n 8
     Want brain=grok and where=none or where=store — or where=stream when
     the bot id arrives only at getExecutor/stream (recovered Cursor-native).
     Dashboard must not move.

  5. After a Bot intros: python3 ~/sand-data/brain-assign.py on <uuid>
     Next createSession with that id hops. Another Bot stays grok.

After Computer recover / host update (stock sand-host again):

  Bindings in ~/sand-data/brain-bindings.json SURVIVE. The host consumer
  does NOT. Recovered hosts may be Cursor-native only (no xAI branch) —
  ensure detects that shape and wraps createCursorInferencePromptSession.

  Re-apply without hand-editing host-main.cjs:

    python3 ~/sand-data/ensure-brain-overlay.py
    # or: python3 ~/sand-data/../tools/doctor.py --fix   (on a clone)

  ensure is idempotent (healthy → "no changes needed"), backs up first,
  and RESTORES host-main on failure (fail closed — never leave a half
  patch that bricks native Grok bots). Hop create/key errors also fall
  back to native Grok loudly.

Daily (no restart):

  python3 ~/sand-data/brain-assign.py list
